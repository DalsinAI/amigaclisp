# AmigaCLISP

A port of GNU CLISP (ANSI Common Lisp) to 68k AmigaOS 3.x: 68040, soft float,
built with OpenAmigaGCC and OpenNDK.

Status: started 5 Nov 2026. Nothing builds yet.

CLISP is GPL-2.0-or-later; this port's patches and build scripts are under the
same licence.

Designed, tested and delivered by The AmigaChrome Team.
